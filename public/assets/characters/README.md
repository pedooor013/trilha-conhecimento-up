# Character image slots

Add transparent PNG illustrations in this folder using these filenames:

- `mago-idle.png`, `mago-speaking.png`, `mago-happy.png`
- `barbaro-idle.png`, `barbaro-speaking.png`, `barbaro-happy.png`
- `ladino-idle.png`, `ladino-speaking.png`, `ladino-happy.png`
- `paladino-idle.png`, `paladino-speaking.png`, `paladino-happy.png`
- `arqueiro-idle.png`, `arqueiro-speaking.png`, `arqueiro-happy.png`
- `heroi-idle.png`, `heroi-speaking.png`, `heroi-happy.png`

Use transparent backgrounds and keep the character centered with some breathing room around the head and feet. The app switches to `speaking` after an incorrect answer and to `happy` after a correct answer. Missing files use the built-in visual fallback until the illustrations are added.
